# Información
Repositorio usado para la entrega de la primera tarea de Ingeniería de Datos.
La base del repositorio contiene un archivo "Historial.txt", que mantiene un historial de la lógica detrás
de cada cambio realizado a través del desarrollo del programa.
El archivo "Prompts.txt" contiene un historial de la conversacion con la IA Gemini de Google, utilizada para
la construcción básica del proyecto.

# Instrucciones de ejecución
Teniendo Docker ejecutado en el PC, abrir una terminal en la base del proyecto, y ejecutar "docker-compose up --build".
